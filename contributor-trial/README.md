# Contributor trial

Read `REPORT.md` for the completed assessment and `receipt.json` for elapsed time.
`protocol.json` and `suitability-criteria.md` record the starting scope. `notes.md`
records the reasoning and accounting finding. `families.md` fixes the new cases.

`exploration.json` contains every development trial, not just the best score.
`frozen.json` records the selected policy and candidate source hash.
`evaluation-lock.json` binds the evaluated methods to that freeze. `runs.json`
contains all interleaved repeats; `summary.json` retains the aggregate and ranges.
`validation.json` and `certificates/` are the exact algebraic evidence.

`demo.svg` is a static, data-derived public-demo chart. It deliberately retains
the two-mass-triangle regression and compares with the best earlier method on each
case, an oracle comparison that is stronger than any one deployed baseline.
`public-story.md` explains what may be claimed. `next-stage.md` gives launch gates.

The experiment is CPU-only and local. It was conducted by the harness's author;
it is not evidence of independent reviewer acceptance or newcomer onboarding.
